All menus should share one visual theme.
Use:
● Clear headers
● Relevant emojis
● Consistent section labels
● Compact tables
● Ten-segment progress bars
● Color-coded status indicators

Color Key
●  Healthy, complete, equipped, friendly, successful, or available🟩
●  Moderate, developing, damaged, uncertain, or neutral🟨
●  Low, strained, limited, or warning🟧
●  Critical, hostile, failed, cursed, or dangerous🟥
●  Mana, knowledge, information, or magical progress🟦
●  Rare, supernatural, epic, or unique🟪
●  Empty, common, or unfilled⬜
●  Locked, hidden, undiscovered, or inaccessible⬛
Progress-Bar Rules
Every progress bar must remain on one line.
The following must remain together:
● Current value
● Maximum value
● Visual progress bar
● Exact percentage
Use exactly ten segments.
Example:
340 / 500 XP  68% ⬜⬜⬜🟩🟩🟩🟩🟩🟩🟩
When space permits:
340 / 500 XP  68% • 160 XP left🟩🟩🟩🟩🟩🟩🟩⬜⬜⬜
Never:
=== PAGE 13 ===
● Split progress-bar segments across multiple lines
● Put the percentage below the bar
● Separate numerical progress from the bar
● Add long descriptions to the progress line
Place the skill or resource label on the previous line when needed.
